# 第三阶段：装备浏览

本阶段接入装备搜索、组合筛选、排序、分页与公开详情，沿用已有目录样式。数据库结构和业务库中的账号、库存、装备数据无需重建。

## 功能范围

- 按装备名称搜索，输入后防抖查询，回车立即提交；支持稀有度多选、分类和排序组合。
- 支持最新上架、价格升序、价格降序和稀有度排序，每页显示 8、12 或 16 件。
- 筛选变化回到第一页，查询条件写入地址；刷新、浏览器前进后退和从详情返回可恢复查询。
- 列表与详情显示价格、品阶、类型、用途、非零属性和库存；售罄装备可查看，库存不超过 5 件时显示低库存提示。
- 详情区分加载、重试和装备不可访问；快速切换条件或详情时，旧响应不覆盖当前结果。
- 接通已有图片字段，暂用原有占位图；图片失败提供备用显示，正式装备美术留到后期。

本阶段没有购物车、数量选择或购买按钮。数量与加购将在第四阶段一起接通，形成实际可操作的流程。没有开展页面重设计。

## 后端行为

`GET /api/equipments` 支持 keyword、rarities、category、sort、page、page_size。关键词只按名称匹配，并把 SQL 通配符当作文字；所有筛选值与排序方式由服务端校验。

筛选后的总数与结果在同一只读事务快照中读取，排序用 id 处理同值次序。库存为零的 on_sale 装备仍公开；off_sale 和 deleted 在列表与详情中都不可访问。`GET /api/equipments/:id` 对非法 ID 返回 422，对不可访问的装备返回 404。

完整参数规则见[数据库与接口设计](02-data-and-api.md)。
