## 启动与学习顺序

本机配置和数据库已经准备好，项目根目录运行 `npm run dev`，访问 http://127.0.0.1:5173/。完整首次初始化步骤见 [README](../README.md)。

可以先按数据的流向阅读：前端 `client/src/views/EquipmentList.vue` → 请求封装 `client/src/api/equipments.js` → 后端入口 `server/src/app.js` → 查询逻辑 `server/src/modules/equipments/equipment.service.js` → 建表文件 `database/schema.sql`。这样能看到一次页面加载如何取到 MySQL 中的装备。

下一阶段实现注册、用户名或邮箱登录、JWT、刷新保持登录、退出以及角色与冻结状态校验；再扩展装备浏览和购物车。
