# 管理端装备图片上传

2026-09-18：新增、编辑装备共用本地文件上传控件，取消扫描项目文件夹的图片下拉框；旧装备原有图片继续兼容。

## 使用

点击装备图片控件，从本机选取 JPG、PNG 或 WebP。限制为 5 MB、1600 万像素、静态图片。上传成功即预览，点击创建装备或保存修改后才改变装备关联图片；上传中禁止保存，失败保留原图并可重新选择同一个文件。未选择新图的编辑保留原图，新建默认使用占位图。

## 接口和保存

- `POST /api/admin/equipment-images`：有效管理员专用。请求体为图片原始二进制，Content-Type 为 image/jpeg、image/png 或 image/webp（不是 multipart）。返回 HTTP 201，`data.image` 为 `/api/uploads/equipments/<sha256>.webp`。
- 后端通过 sharp 实际解码，拒绝伪造类型、损坏图片、动画和过大像素；按图片方向旋转，最长边缩至 2048 像素，重新编码 WebP 并移除原始元数据。
- 临时写入后原子改名；文件名由输出内容哈希生成，不使用原文件名，不会覆盖不同图片。同一图片重试不会重复占用一份文件。
- `GET /api/uploads/equipments/:filename`：公开只读，只接受 64 位十六进制哈希加 .webp。返回 WebP、nosniff 和长期缓存，拒绝目录遍历与任意文件读取。
- 装备原有创建/编辑接口接收返回的 image；保存前检查上传文件存在。其余字段、版本冲突检查、库存和订单逻辑不变。
- 413 表示超过 5 MB；422 表示格式或内容不合法。未登录 401、普通用户及冻结账号 403。

文件保存在 `server/uploads/equipments`，不会写入前端源码或构建目录。该目录已加入 Git 忽略规则；部署、备份和搬迁时，需与数据库一起保留上传目录，部署环境应使用持久磁盘。现有 `/api` 代理即可提供上传和读取，无需数据库迁移。

更换图片、删除装备、取消编辑均不自动删除已上传文件，以免破坏历史订单快照或仍在编辑的表单。因此放弃保存的上传会留下未引用文件，当前课程版不做自动清理；人工清理必须同时检查装备和历史订单引用。后续若多实例部署，再迁移至共享文件存储。
