# 管理端复审修复记录

2026-09-17：修复当前复审发现的问题，保留已经完成的游客登录加购、活动系列、账号角色下单和管理端业务实现。

## 修复内容

- 用户冻结/恢复、订单取消/完成、装备软删除：路由 ID 与接口 ID 按字符串比较，兼容 MySQL 返回数字，避免点击后被错误拦截。
- 三个详情页复用 `createLatestRequest`，每次加载捕获独立的页面代次、路由 ID、Token 与会话 revision。切页和卸载中止旧请求；即使取消未及时生效，旧成功、失败及收尾回调也不能修改新页面。离开 A 再返回 A 同样不能接纳旧 A 的响应。
- 新页面重置操作中状态与确认区，避免旧请求留下永久禁用的按钮。重复点击只发送一次操作请求。
- 网络失败、超时以及 HTTP 5xx 视为结果待确认；不自动重发写请求，不根据旧页面状态推断是否成功。只有重新读取服务器最新详情成功后才解除操作限制；刷新失败仍保留限制。明确的 404/409 业务拒绝提供刷新入口，防止继续用过期状态操作。
- 保持后端现有事务与幂等规则：取消订单只返库一次，重复交付不重写完成时间，软删除仍受未完成订单约束。中止前端请求不能撤销已提交事务，重返页面必须重新读取服务器状态。
- 同步当前数据库表数、管理端进度、游客登录加购和演示账号角色要求，保留旧阶段的历史验收记录。
