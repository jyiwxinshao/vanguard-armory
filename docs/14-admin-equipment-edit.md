# Stage 6.4 装备资料编辑与上下架

接通 `/admin/equipments/:id/edit` 和 `PUT /api/admin/equipments/:id`。从管理详情进入，编辑后回到详情并保留返回列表的条件。本轮无数据库迁移，不实现库存调整或软删除。

## 接口与一致性

- 管理详情 GET 返回额外字段 `edit_version`，由 ID 和可编辑资料的内容计算 SHA-256。版本不包含 stock、created_at、updated_at 或随时间变化的 is_new，库存变动不会导致资料编辑冲突；不依赖秒级 updated_at 判断版本。
- PUT 要求完整的 name/price/rarity/category/image/attack/defense/status/description/series_code/new_until，加上读取时的 edit_version。可选文字和日期可以显式 null 清空，缺字段或未知字段返回 422。复用新增校验，status 仅 on_sale/off_sale；出现 stock 字段即拒绝，不忽略后写回。
- 事务内使用 `SELECT ... FOR UPDATE` 锁定装备，确认存在、未删除且版本匹配，再仅更新白名单资料字段并读取最新结果，提交后返回 HTTP 200 和包含 edit_version 的对象。读回/更新失败回滚。
- 不存在返回 404；已删除或版本不匹配返回 409，不能通过编辑恢复已删除装备。连续保存同一内容不会改变业务字段；内容不同的并发保存只有先完成者成功，后者须加载新资料。
- 装备行锁与订单创建的装备行锁协调，编辑不覆盖扣减/恢复后的实时库存；未访问订单表，历史订单商品快照保持不变。上下架不返库存、不取消已有订单，订单状态仍走独立业务流程。
- 版本是内容冲突检测，不是审计序号或授权凭证：资料改动后完全恢复原值时版本相同。权限始终由服务器校验。

## 前端行为与边界

- 新增与编辑共用 `components/admin/EquipmentFields.vue`，编辑隐藏库存输入，显示“加载时库存”只读参考。价格元/分转换、可选字段清空及 UTC/本地时间转换复用 helper，回填保留秒数，避免无意修改新品期限。
- 已删除装备不显示编辑入口；直接打开编辑地址也只显示不可编辑说明。422 保留表单并展示字段错误；404/409 或网络未知结果停止继续提交，提供明确的“重新加载最新资料（放弃未保存修改）”。不会自动覆盖或重试。
- latest-request、AbortController、账号 revision 与页面加载代次共同隔离旧响应；切换 ID、账号或卸载后旧请求不能覆盖表单或跳转当前页面。
- 取消客户端请求不保证服务器取消保存，未知结果必须重新读取核对。没有跨刷新保存草稿；离开或刷新页面会失去未保存修改。

## 文件入口

- `server/src/modules/admin/equipments/equipment.validation.js`：完整编辑字段校验，拒绝 stock。
- 同目录 `equipment.service.js`：管理详情版本、行锁、事务更新与冲突检测。
- `client/src/views/admin/EquipmentEdit.vue`：加载、编辑、保存、冲突恢复；`EquipmentDetail.vue` 提供入口。
- `client/src/components/admin/EquipmentFields.vue` 与 `client/src/utils/admin/equipment-form.js`：新增/编辑共享字段及转换。

下一小步建议实现独立库存调整，使用操作编号与事务回执防止网络重试重复加减，然后实现有未完成订单保护的软删除。
