# 登录后加购与购物车开放边界

购物车仅向处于 active 状态的普通用户开放，游客不创建、读取或修改本地购物车。相关入口行为如下：

- 游客可以浏览装备列表与详情；点击首页或详情页的“加入购物车”会跳转登录，并保留原页面路径（含查询参数）。登录成功后返回原页面，需要再次点击才会加购，不自动重放。
- `/cart`、`/checkout` 和 `/orders` 均要求登录；游客访问会跳转登录并在完成后回跳。
- 旧版本地游客购物车仅在登录后由 `/api/cart/merge` 兼容恢复，新的游客浏览不再写入本地购物车批次。

该调整的实际实现与回归见[购物车接口约定](02-data-and-api.md#42-购物车)和[开发计划](03-development-plan.md)。
